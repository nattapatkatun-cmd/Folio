🌐 ภาพรวมตลาด (Macro)
วิธีอ่าน
สีขอบซ้ายบอก "ผลต่อพอร์ตเรา" ของการเปลี่ยนแปลงวันนี้ ไม่ใช่แค่ขึ้น/ลง: เขียว = ดีต่อพอร์ต, แดง = กดดันพอร์ต, เทา = แทบไม่เปลี่ยน
• หุ้น (S&P 500, Nasdaq, SET) และทอง ขึ้น = เขียว
• US 10Y yield, ดอลลาร์ (DXY), USD/THB, VIX, น้ำมัน ขึ้น = แดง (ต้นทุนเงินแพง / ดอลลาร์แข็ง / ตลาดกลัว / เงินเฟ้อ)
• USD/THB ขึ้น = บาทอ่อน → DCA กองต่างประเทศได้หน่วยน้อยลง แต่กองที่ไม่ hedge ค่าเงินที่ถืออยู่จะมีมูลค่าเป็นบาทเพิ่ม
• Yield แสดงการเปลี่ยนเป็น bp (1 bp = 0.01%) · กราฟเล็กคือ ~1 เดือนล่าสุด · ชี้ที่การ์ดเพื่อดูคำอธิบาย
ข้อมูลจาก Yahoo Finance อาจช้า ~15 นาที — ใช้ดูภาพใหญ่ ไม่ใช่จับจังหวะรายวัน

วิธีอ่าน
สูง = มักทำให้ตลาดผันผวนแรง (เช่น เงินเฟ้อ CPI, การจ้างงาน, ประชุม Fed/กนง.) · กลาง = มีผลรองลงมา · ปันผล = วันปิดสมุดทะเบียน/จ่ายปันผลของกองที่ถืออยู่
"คาด" = ค่าที่นักวิเคราะห์คาดไว้ · ถ้าตัวเลขจริงต่างจากคาดมาก ตลาดจะขยับแรง · สำหรับ DCA ระยะยาว ไม่จำเป็นต้องหลบวันเหล่านี้ แค่รู้ไว้ว่าทำไมราคาแกว่ง
แสดง: ข่าวสหรัฐ (สูง+กลาง), ข่าวไทย, และข่าวระดับสูงของยุโรป/จีน/ญี่ปุ่น/อังกฤษ · ที่มา Forex Factory + ตารางประชุม Fed/กนง. ทางการ

งบเดือนนี้ ฿ ใช้กับปุ่ม 💰
กดปุ่มด้านบน หรือพิมพ์ถามเองได้เลย เช่น "ถ้าดอลลาร์อ่อนต่อ กองไหนในพอร์ตโดนหนักสุด", "ควรเริ่ม RMF เพิ่มก่อนสิ้นปีไหม" · AI เห็นพอร์ต แผน DCA สัญญาณตลาด และรายรับรายจ่ายของคุณ และค้นข่าวล่าสุดได้
วิธีใช้
• ปุ่มสำเร็จรูป 3 ปุ่มครอบคลุมคำถามที่ใช้บ่อย · ถามต่อได้เรื่อย ๆ AI จำ 10 ข้อความล่าสุดของบทสนทนา
• ทุกคำตอบเริ่มด้วย "สรุป" อ่านบรรทัดแรกก็พอ รายละเอียดอยู่ด้านล่าง · ถ้า AI ค้นข่าว จะมีลิงก์แหล่งข่าวท้ายคำตอบ
• ปุ่ม 💰 ระบบจะเช็กว่ายอดในตารางรวมตรงกับงบไหม ถ้าไม่ตรงจะเตือน
• AI จะไม่แนะนำขาย SSF/RMF และไม่แนะนำขายเพราะข่าวระยะสั้น · ใช้เป็นความเห็นประกอบ ตัดสินใจเองเสมอ
• ต้องการตาราง/ตัวเลขละเอียดแบบเดิม → เปิด "เครื่องมือ AI แบบละเอียด" ด้านล่าง

🔥 Firebase ✓ Hardcoded ในไฟล์แล้ว
Project: folio-5fcd0 — ถ้าได้รับ "Missing or insufficient permissions" ให้อัพเดท Firestore Rules ด้านล่าง
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/nattapat/{document=**} {
      allow read, write: if true;
    }
  }
}
วิธีแก้: ไปที่ Firebase Console → Firestore → Rules → วาง rules ด้านบน → กด Publish
⚠️ Rules ด้านบนเปิด public — ใครก็ตามที่รู้ project id นี้อ่าน/แก้ข้อมูลพอร์ตได้ เหมาะสำหรับทดสอบเท่านั้น หากใช้งานจริงควรเปิด Firebase Authentication (เช่น Anonymous Auth) แล้วเปลี่ยน rule เป็น allow read, write: if request.auth != null;
